Privacy policy — Password Wallet

Last updated: October 20, 2026. This policy describes version 1.0.

Password Wallet is a free password manager. It has no account and no sign-in server. The developer does not collect, receive, or sell personal information. The app does not use analytics, advertising, or tracking.

Nothing is sent off the device

The Android app does not request Internet permission, so it cannot upload the vault. The iPhone app has no network code for the vault. Logins, the master password, and settings stay on the device. Opening a store search in Settings hands a link to the phone’s store app. That is not a vault upload.

What stays on the device

  • The logins you type: title, username, password, website, and notes. They are encrypted.
  • A random salt and an encrypted copy of the vault key, used to check the master password. The master password itself is never stored.
  • Settings: theme, auto-lock, clipboard timer, how often to ask for the master password, and whether the 10-try erase option is on.
  • If biometrics are on, a hardware-wrapped copy of the vault key. The app does not keep a fingerprint or face. The operating system handles biometrics.

Encryption

The vault is encrypted with AES-256-GCM. A random vault key does that encryption. The master password is stretched with Argon2id and a random salt that belongs to this vault. A wrong password cannot read the vault.

Biometric unlock only releases the hardware-wrapped key. On Android that key lives in the Android Keystore, and in StrongBox when the phone has it. On iPhone it is wrapped by the Secure Enclave when the device can create that key, otherwise by the Keychain, and it is available only on this device while the device is unlocked. The master password is required after a restart and again after the number of days you choose.

Guessing and the clipboard

Wrong master passwords make the next try wait longer, up to one hour. Missed fingerprints and face scans do not count. Erasing the vault after 10 wrong master passwords is off unless you confirm it. There is no cloud copy to restore.

Copied secrets are marked sensitive and cleared on this device after the time you pick. The default is 30 seconds. The app does not sync the clipboard to another device.

Backups

The vault file is excluded from Android backup and from iCloud backup. If you lose or erase the device, Password Wallet cannot restore it. You can export an encrypted backup file that has its own password. The app does not upload that file. Importing adds those logins to the wallet already on the device.

Other details

Settings can show cards for other apps. Tapping one opens a store search. Those cards are not on the vault list. There are no ads.

A rooted Android phone or a jailbroken iPhone shows a warning. The app keeps working and does not send that warning anywhere.

The app is not directed at children and does not knowingly collect personal information.

Version 1.0 has no accounts and no sync. If a later version adds either, this policy will change first.

Password Wallet does not run a support server. Use the contact address on the store listing to reach the developer.

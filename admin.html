Facility waitlist

Submissions are listed newest first so you can issue free promo codes in order.

Deploy the Apps Script first

  1. Create a blank Google Sheet.
  2. Extensions → Apps Script → paste facility-waitlist.gs.
  3. Run setupSheet() once.
  4. Deploy as a web app (Anyone can access).
  5. Paste the web app URL into WAITLIST_ENDPOINT in both index.html and admin.html.
  6. Change ADMIN_KEY in the script and match it in the key field below (default placeholder: CHANGE_ME).

Until then, facility form submissions go to simpleassistapps@gmail.com via FormSubmit.

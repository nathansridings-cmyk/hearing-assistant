Rammy Alerts

Add to home screen

This is the phone app. There is no App Store and no Play Store. It works in Safari on iPhone (16.4 or newer) and in Chrome on Android.

Open Rammy Alerts

iPhone

  1. Open Rammy Alerts in Safari. The Chrome app on iPhone cannot add it.
  2. Tap Share. It is the square with the arrow.
  3. Scroll the sheet and tap Add to Home Screen.
  4. Tap Add. The icon is the ram.
  5. Open that icon and pair there. Pairing in the Safari tab does not carry over.

Android

  1. Open Rammy Alerts in Chrome.
  2. Tap the three dots.
  3. Tap Install app. If that is missing, tap Add to Home screen.
  4. Open the ram icon. You can pair before or after. Android keeps the same code.

Loud ring when the phone is locked

While Rammy Alerts is open, a call fills the screen and plays a ringtone. Answer opens the video in the browser.

When the phone is locked, this page cannot ring. ntfy only sends lock-screen Web Push to the ntfy website, not to a page we host. Install the free ntfy app, tap +, and paste the Rammy Alerts code from the family page. Use that topic code, not the pairing code. The pairing code stays on this phone.
